# ShredTracker Frontend

Benjamin Escobar | SWDV 691 Capstone

ShredTracker helps users record workouts, track strength progress,
and monitor weight-loss goals.

This repository contains the user interface. It will communicate
with the backend API to save records and display calculated results.

## Planned MVP Features
- Registration and login
- Add, edit, and delete workouts
- Workout history and strength comparisons
- Weight tracking and progress charts
- Weight-loss goals and progress summaries

## Stretch Feature
Saved workout routines that users can load and adjust before
saving a completed workout.

## Design Documents
The design folder contains the personas, wireframes, storyboard,
and HTML style guide.

## Project Status
Design and setup. Application development has not started.
